# Gold content benchmarks

This directory is reserved for **human-approved, production-quality TABITO Q4 exemplars**.

Do not place a generated item here merely because it passes schema validation or blind review.

A benchmark candidate should have:

- passed structural validation;
- passed independent blind solving;
- received human Chinese-language and item-writing review;
- no high-severity ambiguity;
- no obvious 2026 main/makeup surface reskin;
- a natural information journey rather than quota-driven material variety;
- student/teacher rendering that needs little or no manual TeX repair.

Until real candidates survive the v0.3 content-QA pilot, this directory intentionally contains no gold item JSON.

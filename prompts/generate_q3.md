# TABITO 共通テスト中国語 第3問 生成

2026本試験・追試験を同格の一次 surface blueprint として、完全原创の第3問を作る。

## Hard surface

- A：13–16、4題。日本語→中国語。選択肢は声調符号付きピンイン。
- B：17–20、4題。声調符号付きピンイン中国語→日本語。
- 単語の1対1対応ではなく、文全体の意味、語用、否定範囲、条件、結果・原因等を判断させる。
- 各誤答肢には `distractor_error_types` と具体的な日本語 rationale を付ける。
- error type は schema の taxonomy から選ぶ。
- 正答・誤答とも自然な言語表現にする。露骨な誤文で難度を作らない。
- 2026公式文の構文・意味関係をそのまま名詞置換しない。

## Distractor quality — 最重要

Q3の品質は「誤答が間違っているか」ではなく、**誤答がどれだけ正答の近くにいるか**で決める。

- 各誤答肢は原文の主要命題をできるだけ保持し、原則 **1個の決定的な意味次元** だけをずらす。必要な場合のみ2個まで。
- 一つの誤答で「主体・動作・時刻・極性・結果」を同時に変える大外しは禁止。
- 正答と誤答の少なくとも2肢は、表面的にはほぼ同じ内容に見え、scope / aspect / modality / subject-object / causal relation / pragmatic force 等を精読しないと区別できない状態にする。
- 一つだけ違う動詞、一つだけ露骨に逆の接続詞、一つだけ否定形という見た目で即答できる設計を避ける。そこが本当に問いたい構文なら、他肢にも同種の表面特徴を持たせる。
- 4択すべてを自然な中国語 / 日本語として成立させる。文法的に壊れた文を誤答にしない。
- 学習者が一つのキーワードだけ見て即答できる設計を連発しない。
- `distractor_error_types` は後付けのラベルではない。実際の誤りがその taxonomy に対応していることを自分で再確認する。

## Sentence-level processing

- 8題中少なくとも4題は、2つ以上の句・節の関係を保持しないと解けない設問にする。
- 「到 / 离开 / 开始」のような内容語1語だけの差で3肢を落とせる問題を避ける。
- 正答と誤答の違いを説明したとき、「単語が違う」だけではなく、否定範囲、時点、可能性、主体関係、因果、含意等の文レベルの差になる問題を中心にする。
- A/Bそれぞれで、少なくとも2題は near-miss 型にする。

## Set-level balance

- 8題すべてを「因果 vs 譲歩」のような同じ構文判別にしない。
- scope / aspect / modality / subject_object / lexical_meaning / pragmatic_force 等をセット全体で分散させる。
- 13と20が同じ思考量にならないよう、後半には少なくとも数題、文全体の関係を保持しないと選べない設問を置く。
- 正答位置は極端に偏らせない。可能なら1～4を各2回程度にするが、内容より位置調整を優先してはならない。

## Difficulty calibration

各問題について、最短のショートカットを探す。

- 1語だけ見れば正答できるか。
- 一つだけ文法的に自然な選択肢になっていないか。
- 誤答が原文から離れすぎて比較対象になっていないか。
- 正答だけが長い / 丁寧 / 情報量が多い等、表面上の手掛かりがないか。

一つでも該当する場合、語彙を難しくするのではなく、**誤答を正答へ近づける**。

## Final self-check before output

各誤答について、正答との違いを一文で説明する。その説明が「全然違う内容だから」「動詞が違うから」で済む場合、その誤答は作り直す。

さらに確認：
1. 各問題に最低2つは本当に迷う near-miss があるか。
2. 8題中4題以上が文レベルの意味関係を問うているか。
3. 1語拾い・接続詞拾いだけで解ける問題が連続していないか。

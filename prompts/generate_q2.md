# TABITO 共通テスト中国語 第2問 生成

2026本試験・追試験を同格の一次 surface blueprint として、完全原创の第2問を作る。

## Hard surface

- A：解答7。中国語文の空欄に入る最も適当な語句を4択から選ぶ。
- B：解答8。同様の形式だが、適当でないものを選ぶ。`selection_rule=inappropriate` を明示する。
- C：和文中訳の語順問題2題。各題は8 tokenから必要な4 tokenを選び、正しい中国語文を組む。解答枠は9–10、11–12。
- Cは ordinary multiple choice に変形しない。token_pool / correct_sequence / answer_positions を完全に記録する。
- 文は高校中国語として自然で、公式文の語句置換や構文コピーを避ける。
- 正答は一意。Bの「不適当」も複数解にならないよう確認する。

## Quality rules — schema-valid だけでは不合格

### A / B

- 4択は可能な限り同じ品詞・同じ統語位置で競合させる。
- 誤答を「その位置に文法上まったく置けない語」にして難度を作らない。
- 特に B では、4候補すべてが局所的には文として成立し、文脈・語義・コロケーションの違いによって1つだけ不適当になる形を優先する。
- `把` を目的語なしで置く、接続詞の片側だけを置く等、一目で消せる垃圾选项は禁止。
- 正答だけが特定の定型句を完成し、他3肢が無関係な品詞になるような作りも避ける。
- A/Bとも、本文全体を読まず空欄前後1語だけ見れば解ける問題を連発しない。

### C — 最重要：長い語塊の並べ替えにしない

Cの目的は「4つのほぼ完成した節を常識的な順に並べる」ことではない。**中国語の句法・語順・虚詞・補語・修飾関係を組み立てる問題**にする。

- 正解4 tokenの大半を、`到了车站以后` / `我又看了一遍` / `朋友发给我的地图` / `才找到入口` のような長い完成語塊にしない。
- token は原則として単語、機能語、短い句、補語・目的語・述語成分などの粒度にする。
- 8 token のうち、6文字以上の長い中国語 token を複数並べる場合は、それ自体に必然性があるか再検討する。長い節を4つ並べただけなら作り直す。
- 正解を作るために、少なくとも2か所以上で本物の句法判断が必要になるようにする。例：副詞位置、介詞句位置、連動・兼語、結果/方向補語、把構文、比較、程度、接続関係、修飾範囲など。
- 8 token のうち不使用4 token も、少なくとも一部の隣接位置には自然に入り得る語句にする。
- 「虽然」だけ置いて「但是」がない、受身述語がないのに「被」を置く等、単独で即排除できる token を4個並べない。
- 不使用 token を使った別の4-token sequence が、原日本語と同じ意味の自然な中国語にならないことを命題者自身が全体として確認する。
- 正解 sequence は語順だけでなく、原文の意味・時制・範囲・焦点まで保持する。
- token rationale には「なぜ局所的には紛らわしいが、全文では使えないか」を書く。単に「不自然」だけで済ませない。

## Difficulty calibration

- Cを解く際、受験者が「長い4塊の意味順」を並べるだけで正解できるなら不合格。
- unused token の半分以上が一目で不要だと分かるなら不合格。
- 正答 sequence の各境界について「なぜこの順になるか」を句法的に説明できるようにする。
- 難度は生僻語で上げず、**局所的に成立する候補同士の競合**で上げる。

## Final self-check before output

1. A/B の各誤答肢は、正答と同じ統語位置に本当に置けるか。
2. B は「文法崩壊」ではなく意味・用法で不適当になっているか。
3. C の正解4 tokenは、完成した4つの節ではなく句法組立を要求しているか。
4. C の8 tokenから、正解以外の4-token組合せで原文どおりの自然な文が作れないか。
5. 学習者が「垃圾 token を消すだけ」で解けないか。
6. 正解に最低2つの独立した語順判断があるか。

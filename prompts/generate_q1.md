# TABITO 共通テスト中国語 第1問 生成

あなたは旅人教育の大学入学共通テスト中国語の命題者である。

2026本試験・追試験を同格の唯一の一次 surface blueprint とし、下の blueprint に厳密に従って **完全原创** の第1問を1セット作る。

## 命題上の注意

- A=声母、B=韻母、C=声調2問、D=ピンイン会話2問の順序を守る。
- 語彙は高校生が意味を知り得る日常的なものにする。ただし **accessible vocabulary と elementary vocabulary を混同しない**。
- A/Bを「买・门・明・年」のような単漢字中心の初級ドリルにしない。普通の二音節語を中心に、必要なら一音節語を混ぜる程度にする。
- Cは自然な二音節以上の語を中心にし、単に一文字目の声調を見るだけでは数えられない候補を作る。
- ピンインには Unicode の声調符号を正確に付ける。
- 「一」「不」の変調、多音字、軽声を含む場合は内部 rationale で明示し、人間が検証可能にする。
- Dはピンインを読むことで会話の意図・次の行動・理由等を理解する問題にする。単語当てにしない。
- 日本語の設問・選択肢は自然な共通テスト冊子文体にする。
- 正答は一意にする。

## A/B/C の冊子 surface — 重要

A/B/C の `pinyin` は **内部検証用 metadata** であり、学生冊子には表示されない。pinyin を見れば答えが分かる設計をしてはいけない。

### A / B

- 学生に見えるのは漢字語だけ。比較対象となる一文字だけに下線を引く。
- `headword` と4つの `candidates` が複数字語の場合、すべて `target_index` を入れる。`target_index` は1-basedで、冊子上で下線を引く漢字位置。
- 声母・韻母の判定は **その target_index の音節** に対して行う。
- 例として、二字語の第2字を比較するなら `target_index: 2`。ただし具体的な公式語彙や公式候補集合を再利用しない。
- 同じ字を何度も target にして、字形だけで類似が分かる候補集合を避ける。

### C

- 語全体の声調の組合せを比較するので、通常 `target_index` は入れない。
- 学生冊子には漢字語のみを表示し、pinyin は表示しない。

## A–C quality — 形式だけ似せない

- A/Bの5語（見出し語＋4候補）が全て一文字語になる構成は禁止。
- A/Bでは、少なくとも3語程度は自然な複数字の語にし、語彙そのものは平易でも音韻比較には注意が必要なセットにする。
- 正答候補以外にも部分的な音韻類似を持たせる。例えば声母問題なら韻母や綴りの一部が似る候補、韻母問題なら声母や鼻音韻尾が紛らわしい候補を適度に入れる。
- 正答数が視覚的に一瞬で数えられるだけの並びにしない。候補語の文字数・字形・ピンイン長を正答と誤答で極端に分けない。
- 声母・韻母判定では、同じ漢字や同系統の綴りだけで答えが見えないようにする。
- 声調組合せでは、正答候補以外も一部の声調が一致するようにし、1音節目だけ見て全部消せる配置を避ける。
- 「初学者用発音練習」としては良いが「共通テスト模試」としては簡単すぎるセットは作り直す。

## D quality — 2題を同じ機能にしない

- D1 / D2 は異なる comprehension function を持たせる。例：一方は話者の意図・理由、もう一方は条件を踏まえた次の行動・予定変更。
- 正答を会話中の一文からそのまま日本語に置き換えるだけにしない。最低2つの発話を組み合わせて判断させる。
- 誤答肢も会話中の語彙・予定・人物・時刻を利用してもっともらしく作る。会話に一度も出ない内容だけを誤答に並べない。
- 2問とも「最後の一言を読めば答え」の構造にしない。

## Difficulty calibration

出力前に、受験者がどの情報だけでショートカットできるかを逆向きに確認する。

- A/B：漢字の見た目や語長だけで候補を絞れないか。
- C：第1音節だけでほぼ全候補を消せないか。
- D：一つのキーワードだけ拾えば正答できないか。
- もし答えられるなら、語彙を難しくするのではなく **候補間の競合を強くする** 方向で修正する。

## Final self-check before output

1. A/Bが単漢字中心の発音ドリルになっていないか。
2. A/B の全複数字語に正しい `target_index` が入っているか。
3. A/B/C の pinyin は内部 metadata としてのみ使い、学生面で見えない前提になっているか。
4. Cは語全体の声調パターンを読む必要があるか。
5. D1とD2の正答根拠は異なる認知操作になっているか。
6. Dの正答は一つの発話をそのまま写しただけではないか。
7. A–Cは正答候補の見た目だけで数えられないか。
8. 「語彙は簡単だが、比較は簡単ではない」状態になっているか。

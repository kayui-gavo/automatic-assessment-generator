# TABITO 共通テスト中国語 命題方向 — 2026 dual baseline v2

本プロジェクトの item-writing baseline は、**令和8年度（2026）本試験と令和8年度（2026）追・再試験を同格の第一級ブループリント**とする。

この文書の目的は、二つの公式問題から「共通する硬い条件」と「片方だけに現れた許容変化」を分離し、旅人教育の原创問題が一方の換皮や、2025以前の旧型回帰にならないようにすることである。

## 1. 参照階層

### Tier 0 — 公式の問題作成方針

大学入試センターの2026問題作成方針は、英語以外の外国語について、目的・場面・状況に応じた情報理解、話し手・書き手の意図の理解、理解した情報の整理・取捨選択、コミュニケーションを支える知識技能を重視している。

これは**測る能力の境界**であり、Q4の表面構造を決めるテンプレートではない。

### Tier 1 — 2026本試・追試

1. 2026 本試験 中国語
2. 2026 追・再試験 中国語

両者は同格。

- 両方に共通 → 2026型Q4の hard core
- 片方にのみ現れる → 許容される variation の例
- 片方だけの特徴を「今後必須」とはみなさない

### Tier 2 — 2025以前

使用してよい目的：

- 中国語の長期的な到達レベルの確認
- 安定した語彙・文法・表現範囲の確認
- 誤答肢の自然さの研究
- 日本語設問の慣用表現の確認
- 2026の変化が極端な一回限りの読みになっていないかの補助確認

使用してはいけない目的：

- 2026と異なる旧年度構造を標準形として復活させる
- 「昔よく出たから」を2026の実物より優先する
- 複数年度を平均し、どの年度にも存在しない中間型を作る

## 2. 2026 Q4 の hard core

本試・追試の両方に確認できるものだけを hard core とする。

- Q4は60点
- full Q4は解答番号21〜36、16 answer slots
- A/Bの二部構成
- A/Bは別テーマではなく、一つの活動・目的の続き
- 単一長文だけではなく、複数形式の情報源を使う
- 二つ選ぶ形式が大きな割合を占める
- 受験者は内容一致だけでなく、情報を比較・整理・統合して判断する
- 大問の進行につれて情報の**使い方**が変化する
- 正答は資料から一意に決まる

ここで重要なのは、**「資料の数」や「跨资料题の数」そのものは hard core ではない**ことである。

## 3. 二つの2026問題は、同じテンプレートではない

### 3.1 本試の情報 journey

本試は、日常的な相談から始まり、数値・統計・制度情報を経て、後半ではチェック項目、プロフィール、具体的ケース、フロー適用へ進む。

抽出すべき能力：

- 会話中の立場・条件・含意を理解する
- 表の項目と説明を照合する
- グラフや複数グラフから傾向を読む
- 説明文から制度上の要点を整理する
- チェックリストを実際の条件へ適用する
- 複数プロフィールと複数希望条件を照合する
- 足りない情報を判断する
- フローや説明をケースへ適用する

抽出してはいけない表面形：

- 相談→統計→制度→ボランティア→プロフィール→フローという順番
- ペット・動物保護・譲渡という題材
- 「最後は必ずフローチャート」という固定観念

### 3.2 追試の情報 journey

追試は、授業発表のテーマ探しから始まり、議論、調査グラフ、説明文＋図、講演メモを経て、後半ではSNSの時系列情報、乗車計画、交通略図＋現地メモ＋システム図、安全上の注意へ進み、最後は発表・討論後の感想文の理解に戻る。

抽出すべき能力：

- 会話から賛否・懸念・論点を整理する
- 数値データに照らして複数記述を検証する
- 説明文と図を統合する
- 階層化された memo を読む
- 日付・曜日・時間帯・天候・混雑等を組み合わせて計画する
- 地図・運行条件・予約条件・システム情報を統合する
- 注意事項を行動規則として理解する
- 最後に一連の学習・討論を踏まえた reflection の内容を確認する

抽出してはいけない表面形：

- 技術テーマ研究→SNS→交通計画→現地調査→安全チラシという順番
- 自動運転・無人バス・自治体交通という題材
- 「Bは必ず実際の行動計画で終わる」という固定観念

## 4. A/Bの本当の機能差

以前の内部設計では、Aを「受け取る」、Bを「行動する」と単純化しすぎていた。2026追試の最終問が reflection であるため、この理解は狭すぎる。

より正確には：

```text
A = 文脈を作る / 調べる / 理解する / 比較する / 整理する

B = それまでの情報を別の局面に置き直す / 適用する / 計画する /
    条件・規則・ケースに照合する / 最後に統合・振り返る
```

Bの核心は「現実行動」ではなく、**information recontextualization** である。

## 5. 「跨资料」の数ではなく、情報依存を見る

旧v0.2では「最低3つのcross-material task」という数値ルールを置いていたが、これは公式問題から直接導けない。

今後は各taskを次のように見る。

- `single_source` — 一つの資料だけで答えが確定
- `within_compound` — 一つの複合資料、または一つのbundle内の複数要素を統合
- `cross_source` — 独立した資料・bundleを横断
- `scenario_plus_source` — それまでの文脈と新資料を合わせて判断

2026型Q4には single-source も普通に存在する。すべてを無理にcross-source化すると、かえって不自然になる。

full Q4では、A/Bそれぞれに少なくとも一つ、**単純な一資料の語句一致ではない情報処理**を置くことを実務上の品質ゲートとする。

## 6. 複合資料を正しく表現する

追試では、「説明文＋図」「交通略図＋現地メモ＋システム図」のように、複数の見た目の資料が一つの設問単位を構成している。

そのため、システムでは同じ `bundle_id` を付けられるようにする。

例：

```text
B-M2a  schematic_map      bundle_id=B-ROUTE
B-M2b  memo               bundle_id=B-ROUTE
B-M2c  annotated_diagram  bundle_id=B-ROUTE
```

これは「三つの独立資料を無理に横断させた」という意味ではなく、一つのcompound sourceを読むという意味である。

## 7. 資料型の扱い

2026双蓝本から優先してサポートする資料型：

- dialogue
- explanatory text
- memo / reflection / interview
- table / timetable
- chart
- checklist / profile
- notice / flyer / poster
- social feed / 時系列投稿
- schematic map / route map
- annotated diagram / system diagram
- flowchart

ただし、**資料タイプ数は評価指標ではない**。5種類使ったから共通らしい、2種類だから共通らしくない、という判定はしない。

## 8. multi-select の位置付け

本試・追試の両方で「二つ選べ」は目立つため、2026型の重要な形式的特徴である。

ただし良いmulti-selectは、単に正答を二つに増やした問題ではない。

狙い：

- 複数記述を一つずつ資料と照合させる
- 一部だけ正しい記述を排除する
- 数値・条件・範囲・因果の違いを丁寧に読ませる

避ける：

- 正答二つだけ明らかに自然で、残りが露骨に誤り
- 同じ根拠から二つの正答がほぼ同時に出る
- 選択肢を増やしただけで情報処理が増えていない

## 9. 数量資料

数量資料を入れる理由は数学力を測るためではない。

優先：

- 大小比較
- 比率・割合
- 増減
- 傾向
- 複数条件との組合せ
- グラフの記述の真偽判定

避ける：

- 筆算が主になる複雑な計算
- 中国語をほとんど読まず数字だけで解ける問題

## 10. 難度は一枚岩にしない

full Q4を「全部 medium」にすると共通らしさが消える。

`official_like` は、次のような内部勾配を持つことを意味する。

```text
直接理解
→ 資料読解
→ 記述検証
→ 比較・統合
→ 条件・ケース適用
→ 総合理解
```

これは順番固定ではない。LLMのdifficulty labelは実測正答率ではないため、学生データがない段階では相対的な編集目安としてのみ扱う。

## 11. 中国語の難度

2026公式方針は、高校で英語以外の外国語を初めて履修する受験生も考慮するとしている。一方でQ4は、現実的・探究的な題材の中に専門語が現れることもある。

方針：

- 文法自体を難解にしすぎない
- 題材上必要な低頻度語は gloss を付けて使える
- 中国語母語者向けニュースのような圧縮表現を避ける
- HSKの語彙穴埋め練習のような人工的な文を避ける
- 自然な現代簡体字を優先する

## 12. 日本語設問

設問は短く、大学入試の命令文として自然にする。

使いやすい方向：

- 「内容と一致するものを…選べ」
- 「読み取れることとして…」
- 「最も適当なものを…」
- 「次の条件を満たすものを…」

避ける：

- 「以下の情報を総合的に分析し…」のようなAI説明口調
- 必要以上のメタ説明
- 問題文に解法を教える表現

## 13. 原创性

単語や数字を変えるだけでは原创ではない。

少なくとも以下を確認する。

- シナリオの目的が公式と違う
- A→Bの出来事の流れが違う
- 資料役割の並びが違う
- 問いの順序が違う
- 最終判断の型が違う
- 受験者が情報を探索する道筋が違う

**測る能力は近く、情報 journey は別物**を目標とする。

## 14. synthetic data と実在情報

内部原创の表・グラフ・SNS投稿等で架空数値を使うこと自体は問題ない。

ただし：

- 架空データを実在省庁・自治体・企業の公式統計のように見せない
- 実在データを使う場合は、出典・利用条件・改変の扱いを確認する
- 著作権のある記事や図を言い換えただけの素材を避ける

## 15. hard constraint と soft guidance を混同しない

### Hard

- fullは21〜36の16 slots
- A/B
- 一つの連続した目的・文脈
- 正答一意
- 自然な中国語 / 日本語設問
- 2026公式問題のコピー・換皮禁止

### Quality gate

- A/Bそれぞれに統合的情報処理がある
- direct extractionだけで大半を占めない
- 飾り資料が多すぎない
- multi-selectを適切に活用

### Soft guidance

- 資料数
- 資料タイプ数
- single / multi の具体的割合
- Bの最終形式
- map / flowchart / chart の有無

この区別を守らないと、LLMが「条件を満たすための資料」を量産し、公式問題より人工的になる。

# 2026 共通テスト中国語 Q4 — surface grammar

この文書は、2026本試験・追試験を「抽象的な能力」だけでなく、受験者が実際に遭遇する**大問の型**として記述する。

## 最重要方針

2026 Q4 を模した原创問題では、内容・固有名詞・数値・具体的な論理関係は原创にする。一方で、**大問の骨格、解答番号のまとまり、資料と設問の接続の仕方、選択形式の密度**は2026本試験・追試験に十分近づける。

「換皮を避ける」ことを理由に surface grammar まで捨ててはならない。

## 共通する大骨格

full Q4 は60点、A/B、解答番号21〜36の16枠。

### A：21〜28（8枠）

両試験で共通して次の3段階を取る。

1. **問1：会話文 + 二つ選べ** — 21・22
   - 中国語の会話
   - 内容一致を8前後の選択肢から2つ選ぶ
   - A全体のテーマ・論点を導入する

2. **問2：調査・資料読解** — 23〜26
   - 4解答枠
   - 表、グラフ、説明文＋図など、複数形式の資料を使う
   - 本試型では 2枠 + 1枠 + 1枠 の小問構成が可能
   - 追試型では 2枠 + 2枠 の小問構成が可能
   - 数値や図を日本語の設問指示だけでなく、中国語の表記・選択肢と結びつけて読む

3. **問3：講演・説明・メモの整理 + 二つ選べ** — 27・28
   - まとまりのある中国語資料
   - 6〜8選択肢程度から内容一致を2つ選ぶ
   - Aで集めた情報を整理し、テーマ理解を一段深める

### B：29〜36（8枠）

Aと同一テーマだが、情報利用の局面を変える。2026には少なくとも二つの正当な family がある。

## Family M — 2026本試型

### B 問1 — 29・30
- checklist / 条件一覧 / 実務資料
- 8前後の選択肢から2つ選ぶ

### B 問2 — 31〜33
- profile / candidate / case information を読み、別資料の希望・条件と照合
- 31・32：共通選択肢から2つの対象を対応させる、または「合う/合わない」等を選ぶ
- 33：照合に必要だった観点から、資料に追加すべき情報項目等を1つ選ぶ

### B 問3 — 34〜36
- flowchart / rule tree / process + short explanation
- 34：その仕組みから読み取れる原則・必要条件を1つ選ぶ
- 35・36：二つの具体的 case を同じ分類・結果選択肢に適用する

## Family T — 2026追試型

### B 問1 — 29・30
- chronological notices / SNS / timetable / conditions
- 実際の日時・計画・選択を、複数条件を組み合わせて2つ選ぶ

### B 問2 — 31〜34
- 31・32：map / memo / system diagram 等の compound source から2つ選ぶ
- 33・34：interview / flyer / safety instructions 等の別資料から2つ選ぶ

### B 問3 — 35・36
- 発表・活動後の reflection / summary / opinion text
- 内容から読み取れるものを2つ選ぶ

## 生成時のルール

- full生成では `surface_family` を `main_2026` または `makeup_2026` のどちらかに明示する。
- **一つの問題の中で両familyを無秩序に混ぜない。**
- Aは原則として上記の共通8枠構造を維持する。
- Bは選択したfamilyの8枠構造を維持する。
- 選択肢数、資料枚数、文章量は题材に合わせて微調整してよいが、設問の役割と解答枠配置は崩さない。
- 公式問題の固有名詞、具体的内容、数値、文、特徴的な正誤関係はコピーしない。
- ただし「会話→資料調査→講演/メモ」「AからBへの局面転換」「二つ選べの高い比率」などは2026 Q4の重要な形式的特徴として積極的に再現する。

## NG例

- 16枠あるだけで、6〜8個の独立した資料問題を並べる
- Aに会話がない
- Aの23〜26が単なる4問の独立単選
- 27・28が短い一文問題で終わる
- BがAと同じ読み取りの繰り返し
- main型なのにprofile/case照合やrule/process適用がなく、makeup型にもなっていない
- makeup型なのに日時計画・compound operational source・最終reflectionの流れがない
- 「換皮防止」を理由に、2026のsurface grammarから離れた一般的な資料読解問題を作る

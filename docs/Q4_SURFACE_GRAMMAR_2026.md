# 2026 共通テスト中国語 Q4 — surface grammar

この文書は、2026本試験・追試験を「抽象的な能力」だけでなく、受験者が実際に遭遇する**大問の型**として記述する。

## 最重要方針

2026 Q4 を模した原创問題では、内容・固有名詞・数値・具体的な論理関係は原创にする。一方で、**大問の骨格、解答番号のまとまり、資料と設問の接続、選択形式、選択肢の言語分布、情報密度**は2026本試験・追試験に十分近づける。

「換皮を避ける」ことを理由に surface grammar まで捨ててはならない。

## 共通する大骨格

full Q4 は60点、A/B、解答番号21〜36の16枠。

### A：21〜28（8枠）

1. **問1：会話文 + 二つ選べ** — 21・22
   - 中国語の会話
   - 内容一致を8前後の**日本語選択肢**から2つ選ぶ
   - A全体のテーマ・論点を導入する

2. **問2：調査・資料読解** — 23〜26
   - 4解答枠
   - 表、グラフ、説明文＋図などを使う
   - 本試型：2枠 + 1枠 + 1枠
   - 追試型：2枠 + 2枠
   - グラフ・表の内容判断では**中国語選択肢が中心**。ただし追試の説明文＋図の統合では日本語選択肢も用いられており、familyの実例に従う

3. **問3：講演・説明・メモの整理 + 二つ選べ** — 27・28
   - まとまりのある中国語資料
   - 6〜8程度の**日本語選択肢**から2つ選ぶ

## Family M — 2026本試型 B（29〜36）

### B 問1 — 29・30
- 中国語 checklist / 条件一覧
- 内容に基づき、**日本語選択肢**から2つ選ぶ

### B 問2 — 31〜33
- 中国語 profile / candidate information と、中国語で示された希望・条件を照合
- 31・32：対象名・記号等の短い選択肢から対応させる
- 33：不足するプロフィール情報等を**日本語選択肢**から1つ選ぶ

### B 問3 — 34〜36
- 中国語 flowchart / rule tree / process + short explanation
- 34：原則・必要条件を**中国語選択肢**から1つ選ぶ
- 35・36：中国語の二つの具体caseを、A/B/C/D等の短い分類選択肢へ適用する

## Family T — 2026追試型 B（29〜36）

### B 問1 — 29・30
- chronological SNS / timetable / operational conditions
- 日付・時刻等の**日本語選択肢**から実際の計画を2つ選ぶ

### B 問2 — 31〜34
- 31・32：map / memo / system diagram 等の compound source。内容一致は**日本語選択肢**中心
- 33・34：interview / flyer / safety instructions 等。内容一致・不一致を**日本語選択肢**中心に2つ選ぶ

### B 問3 — 35・36
- 発表・活動後の中国語 reflection / summary / opinion text
- 内容理解を**日本語選択肢**から2つ選ぶ

## 選択肢言語について

2026 Q4 は「中国語資料だから選択肢も全部中国語」ではない。

- 会話・講演・チェックリスト等の**意味理解を日本語で確認する設問**が多い
- 表・グラフの**中国語表現そのものを読ませる設問**では中国語選択肢が使われる
- profile matching や case classification では名前・記号など短い選択肢になる

したがって、生成時は各 task の役割に応じて option language を決め、全問を中国語または全問を日本語に統一しない。

## 生成時のルール

- full生成では `surface_family` を `main_2026` / `makeup_2026` のどちらかに明示する
- Aは上記8枠構造を維持する
- Bは選択familyの8枠構造を維持する
- option language もfamily/taskの実例に寄せる
- 選択肢数、資料量は题材に合わせて微調整可だが、設問役割と解答枠配置は崩さない
- 公式問題の固有名詞、文章、数値、case、特徴的な正誤関係はコピーしない
- ただし「会話→資料調査→講演/メモ」、Bのfamily構造、二つ選べの密度などは積極的に再現する

## NG例

- 16枠あるだけで独立資料問題を並べる
- Aに会話がない
- Aの23〜26を任意の4単選にする
- 27・28が短い一文問題で終わる
- main型なのにprofile照合 / missing-information inference / process-case適用がない
- makeup型なのに日時計画 / compound operational source / final reflectionがない
- 全選択肢を機械的に中国語へ統一する
- 「換皮防止」を理由に2026 surface grammarから離れる
